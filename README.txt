NOTA SERVICE DR PRINT — VERSI STAMPEL & TANDA TANGAN

Versi ini sudah memuat gambar tanda tangan dan stempel yang Anda unggah di ChatGPT.
- Tidak ada logo di kepala nota.
- Stempel DR Print dan tanda tangan otomatis tampil pada bagian "Hormat Kami".
- Tidak perlu mengunggah stempel/tanda tangan lagi setiap membuat nota.
- Foto barang dicetak pada halaman kedua.
- Nota A4 portrait, total otomatis, arsip tersimpan di browser perangkat.

INSTALASI IPHONE:
1. Unggah seluruh isi ZIP ini ke repository GitHub.
2. Buka Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
4. Setelah GitHub Pages aktif, buka alamat situs di Safari iPhone.
5. Tekan Share > Add to Home Screen > Add.
6. Buka aplikasi sekali saat internet tersedia. Setelah file tersimpan, aplikasi dapat digunakan offline.

DATA:
Arsip nota tersimpan lokal di browser iPhone. Jangan hapus data situs Safari bila ingin mempertahankannya. Data tidak otomatis tersinkron ke perangkat lain.

CETAK:
Pilih Pratinjau / Cetak, lalu gunakan AirPrint atau menu Share untuk menyimpan PDF.
